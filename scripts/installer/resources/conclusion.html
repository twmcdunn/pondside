@STYLE@

Pondside is installed

Open Pondside from your Applications folder, then open a .ly file or create a new score.

If something is missing

If you chose an agent

Run claude (or opencode) once in Terminal to sign in, then pick it in Pondside ▸ Settings (⌘,). Open a new Terminal window first so it finds the command.

SuperCollider, MuseScore and the agents are downloaded while installing; without an internet connection they are skipped. Pondside tells you when a feature needs a tool that isn't there, and you can run this installer again at any time.

Where things went

  • /Applications/Pondside.app
  • /Library/Application Support/Pondside/Toolchain — LilyPond, FluidSynth and the SoundFont
  • /usr/local/bin/pondside — the command-line tool, if chosen
  • ~/.local/bin/claude, ~/.opencode — the agents, if chosen (each vendor's own install)

To uninstall Pondside, delete the first three items; the agents are yours to keep or remove.

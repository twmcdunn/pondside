Welcome to Pondside

Pondside is a notation editor for LilyPond scores, with tools for scores that include live electronics. It is open-source software for academic research.

This installer puts Pondside in your Applications folder, together with the tools it needs. Nothing else has to be downloaded or installed by hand.

  • LilyPond @LILYPOND_VERSION@, the engraver. Always installed.
  • FluidSynth and a General MIDI SoundFont, for audio mockups.
  • SuperCollider and MuseScore Studio, if you want them. They are downloaded from their projects during installation.

On the Installation Type page, untick anything you don't want. Tools you already have are detected and still work with Pondside.

Pondside @PONDSIDE_VERSION@ for @ARCH_LABEL@ · requires macOS 14 or later.
